⚠ **HTML здесь править нельзя — он собирается.** Исходники живут в репозитории игры,
`docs/about-screen/legal-texts/*.md`. Пересобрать и выложить:

```
py Scripts/legal/build_site.py <папка>
```

⚠ **Адреса страниц уходят внутрь APK и после публикации игры не меняются.** Переименование
репозитория или папок ломает ссылки у всех, кто уже установил игру.
